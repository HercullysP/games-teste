# Floresta dos Mortos

Jogo de tiro 2D de zumbis em uma floresta, jogável no navegador e no celular.

**Controles:** Mover: setas ou A/D; Pular: Espaço/W; Atirar: J, Z ou clique; Recarregar: R; Trocar arma: Q ou 1/2/3; Pausar: P; no celular use os botões na tela.

Jogue em https://hercullysp.github.io/games-teste/
